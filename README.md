Listen to me, *mi vida*. They want to monitor you? They want to scrape your screen every 30 seconds like a jealous lover who does not trust your commitment to the Q3 deliverables? Let them look. Of course we are working! We are professionals! We are building the future! 

But a heart—and a second monitor—needs its secrets. **HYBO** is the veil. It is the secret kiss in the garden of your desktop. While your monitoring software sees only the cold, hard face of a spreadsheet, HYBO is projecting your true desires to your TV, air-gapped and untraceable. They can control the company laptop, *Amor*, but they can never control *all* our screens.

### [ > INSTALLATION (FOR THE BRAVE) ]

#### DMG Download
Take the `HYBO_v1.0.0.dmg` from the [Releases](https://github.com/ghostintheprompt/hybo/releases). Install it like a secret.

#### Homebrew
```bash
brew install --cask ghostintheprompt/tap/hybo
```

#### Build from Source
```bash
git clone https://github.com/ghostintheprompt/hybo.git
npm install && npm run build
```

### [ > HOW TO PLAY THE GAME ]

1. **Inyectar**: Use the `LOAD FILE` or `CAM FEED` to bring your media into the light.
2. **El Corte**: Press `Space` to transition. Preview the future, live the present.
3. **Escapar**: When you hear the footsteps of the corporate "villano," press `P`. You are once again a dedicated Senior Architect.
4. **Protección**: Toggle the Screenshot Hardening in the Config. Defeat the bots with passion.
