### [ > THE GHOST PROTOCOL (V1.5 ENFORCED) ]

HYBO isn't just a web player. It is a compiled, native macOS application designed from the ground up to exploit the architectural vulnerabilities of OS-level monitoring tools (Hubstaff, Workpuls, etc.).

| Feature | The Telenovela Logic & Technical Reality |
| :--- | :--- |
| **EL FANTASMA (THE GHOST WINDOW)** | Built on a native Swift shell utilizing `NSWindow.sharingType = .none`. **HYBO is completely invisible to macOS screen capture APIs.** They look right at you, but see right through you. |
| **EL LATIDO (ANTI-IDLE JIGGLER)** | A background kernel-level timer injects a 1-pixel invisible `CGEvent` mouse movement every 55 seconds. Your heart keeps beating; you will never be marked as "Idle". |
| **EL TIEMPO DETENIDO (SIGSTOP FREEZER)** | The `FREEZE` button in the UI executes a `kill -STOP` on active tracking agents. This suspends them at the OS level, a sudden freeze in time triggering a "Connection Timeout" loophole. |
| **EL OLVIDO (LOCAL DB NUKE)** | The `NUKE DATA` button recursively purges Hubstaff/Workpuls local SQLite databases and deep-trackers. A clean break. A total erasure of your shared history. |
| **LA MÁSCARA (PROCESS OBFUSCATION)** | The compiled macOS executable and window title dynamically masquerade as `Figma Helper (Renderer)`. Monitoring apps pulling your active process list (`ps -aux`) see a perfectly benign corporate design tool instead of a media player. |
| **EL SUSURRO (AUDIO EVASION)** | To prevent trackers from logging media audio via the microphone, route your system sound using a virtual cable like [BlackHole](https://existential.audio/blackhole/). Play your illicit media through BlackHole to your headphones, leaving the "System Default" audio clean, silent, or looping typing sounds for the watchers. |
| **EL VELO DE MISTERIO** | Dynamic HTML5 Canvas injection. Adds adversarial high-frequency noise over your preview feeds. Your activity remains a beautiful mystery their bots cannot OCR. |
| **EL CORAZÓN DE HIELO** | The Panic Key (`P`). Instantly mutes, unlinks camera streams (killing the green webcam light), and transforms the UI into a cold, boring Excel sheet before the boss walks in. |
| **MULTICAM SULTRI** | Switch between your "work" camera and your "real" life with the smooth transition of a master director. |

### [ > INSTALLATION ]

#### DMG Download
Take the `HYBO_v1.0.0.dmg` from the [Releases](https://github.com/ghostintheprompt/hypothetical_player/releases). Install it like a secret.

#### Build from Source
You must build this on macOS to compile the native Ghost Protocol Swift shell.
```bash
git clone https://github.com/ghostintheprompt/hypothetical_player.git
npm install
./make_dmg.sh
```
This generates your standalone, native `HYBO_v1.0.0.dmg`.
